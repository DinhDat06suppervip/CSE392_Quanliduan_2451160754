# CSE392_Quanliduan_2451160754
Dự án: Website quản lý nhân viên
1. Mục tiêu

Xây dựng website giúp doanh nghiệp quản lý thông tin nhân viên, phòng ban, chức vụ và tiền lương.

2. Công nghệ sử dụng
- HTML, CSS, JavaScript.
- PHP.
- MySQL.
- XAMPP.
3. Đối tượng sử dụng
- Admin: Quản lý toàn bộ hệ thống.
- Nhân viên: Đăng nhập và xem thông tin cá nhân.
4. Chức năng chính
1. Đăng nhập, đăng xuất.
2. Thêm, sửa, xóa nhân viên.
3. Tìm kiếm nhân viên.
4. Quản lý phòng ban.
5. Quản lý chức vụ.
6. Quản lý tiền lương.
7. Thống kê nhân viên.
5. Cơ sở dữ liệu

Dự kiến gồm 5 bảng:
- employees: Nhân viên.
- departments: Phòng ban.
- positions: Chức vụ.
- users: Tài khoản.
- salaries: Tiền lương.
6. Các bước thực hiện
1. Phân tích yêu cầu.
2. Thiết kế cơ sở dữ liệu.
3. Thiết kế giao diện.
4. Lập trình PHP.
5. Kết nối MySQL.
6. Kiểm thử và hoàn thiện.
